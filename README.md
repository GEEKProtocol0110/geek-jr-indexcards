# Geek Jr Index Cards

**Status: earlier picture-word prototype.** Its 112-card First Words deck is incorporated into the active [Geek Jr](https://geekjr.xyz/) site. Improve the live lessons, illustrations, local learner profiles and backups in [geek-jr](https://github.com/GEEKProtocol0110/geek-jr). [GEEK HQ](https://www.geekprotocol.xyz/) is the main ecosystem hub.

This repository preserves the original Next.js card loop and text prompts for reference. Missing historical image paths were not imported into the live app. It is not the authoritative child-learning release or storage implementation.

For prototype development, install the dependencies described by package.json and run `npm run dev`. See the active Geek Jr contribution and privacy documents before reusing content. Earlier unresolved README merge markers have been removed.
